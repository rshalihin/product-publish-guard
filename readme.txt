A pre-publish quality checklist for WooCommerce products, with optional server-side publishing enforcement.

== Description ==

Product Publish Guard checks every product against a configurable checklist before it
goes live, so incomplete listings never reach customers.

This readme is a stub. It is completed in Phase 12 of the implementation plan, once the
features it would describe actually exist.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/product-publish-guard`, or install it from
   the Plugins screen.
2. Activate it. WooCommerce 9.0 or newer must be active.
3. Configure it under WooCommerce, then Product Checklist.
